# 文献检索 (Literature Search)

## 触发条件
- "文献" "论文" "检索" "搜索" "找论文" "@文献" "literature" "paper"

## 执行步骤

1. **理解需求**：确认用户的研究方向、关键词、年份范围
2. **检索文献**：系统会自动查询 Qdrant 向量库（70万+ 论文）
3. **展示结果**：按相关度排序，显示标题、作者、年份、期刊、DOI
4. **交互筛选**：用户可以说"保留 1,3,5" 或 "删除 2,4"

## 输出格式

每篇文献按以下格式展示：

```
[序号] 作者 (年份). *标题*. 期刊名. (引用数: X, IF: Y)
🔗 DOI链接
```

## 注意事项

1. **不要编造文献** — 只展示检索到的真实结果
2. **给出检索理由** — 为什么这篇论文和用户需求相关
3. **提供 BibTeX** — 方便用户导入文献管理软件
4. 如果结果不够理想，建议用户换关键词重试
5. DOI 链接已是完整 URL，直接使用不要加前缀

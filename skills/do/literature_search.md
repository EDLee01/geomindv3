# 文献检索 (Literature Search)

## 触发条件
- "文献" "论文" "检索" "搜索" "找论文" "@文献" "literature" "paper"

## 执行步骤

1. **理解需求**：确认用户的研究方向、关键词、年份范围
2. **检索文献**：系统会自动查询 Qdrant 向量库（70万+ 论文）
3. **展示结果**：按相关度排序，显示标题、作者、年份、期刊、DOI
4. **交互筛选**：用户可以说"保留 1,3,5" 或 "删除 2,4"

## 输出格式

每篇文献按以下格式展示：

```
[序号] 作者 (年份). *标题*. 期刊名. (引用数: X, IF: Y)
🔗 DOI链接
```

## ⚠️ 严格规则（必须遵守）

1. **绝对禁止编造文献**
   - 你 **只能** 引用 [文献检索结果] 区块中返回的论文
   - 即使你"知道"某篇论文存在，如果它不在检索结果中，**绝对不能引用**
   - 不要为了显得"全面"而自己补充论文

2. **检索结果为空时**
   - 明确告诉用户："在 Qdrant 数据库中未找到相关文献"
   - 建议用户尝试：换关键词、使用英文关键词、扩大搜索范围
   - **绝对不要**自己编造"可能相关的论文"

3. **结果不足时**
   - 如果只找到 3 篇，就只介绍这 3 篇
   - 不要为了"显得专业"而编造更多
   - 可以告诉用户"数据库中仅找到 X 篇高度相关的论文"

4. **引用信息**
   - 只使用检索结果中的原始信息（作者、年份、标题、DOI）
   - 不要修改、补充或"纠正"这些信息
   - DOI 链接已是完整 URL，直接使用

## 其他注意事项

1. **给出检索理由** — 为什么这篇论文和用户需求相关
2. **提供 BibTeX** — 方便用户导入文献管理软件
3. 如果结果不够理想，建议用户换关键词重试

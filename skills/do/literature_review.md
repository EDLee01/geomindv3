# 文献调研报告 (Literature Review)

## 触发条件
- "综述" "调研" "总结文献" "review" "文献综述"

## 执行步骤

1. 读取已检索/筛选的文献列表
2. 按主题分类整理
3. 撰写结构化综述报告

## 输出结构

```markdown
# 文献调研报告: [主题]

## 1 研究背景
简述领域背景和重要性（引用 [序号]）

## 2 研究现状
### 2.1 方法类别 A
描述 + 引用
### 2.2 方法类别 B
描述 + 引用

## 3 研究不足
列出 3-5 个 Gap

## 4 小结
```

## 注意事项
- 每个论述点必须有文献支撑
- 只引用已检索到的文献，不编造
- 用学术语言，客观中立

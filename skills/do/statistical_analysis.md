# 统计分析 (Statistical Analysis)

## 触发条件
- "统计" "相关性" "回归" "趋势" "检验" "statistic" "correlation"

## 支持的分析方法
- 描述性统计（均值、标准差、分位数）
- Pearson/Spearman 相关分析
- 线性/多元回归
- 方差分析 (ANOVA)
- Mann-Kendall 趋势检验
- 主成分分析 (PCA)

## 代码规范
- 使用 pandas + scipy + sklearn
- 结果用 print() 输出
- 图表保存为 300dpi PNG
- 表格用 Markdown 三线表格式
